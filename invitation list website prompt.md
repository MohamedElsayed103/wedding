====================================================

MOBILE FIRST DESIGN

====================================================



Assume that 95% of visitors will open this website on a smartphone after scanning a QR code or tapping a WhatsApp link.



Design for mobile FIRST.



Desktop is secondary.



The mobile version should feel like an interactive animated movie.



Requirements:



• Responsive from 320px to 1920px

• Comfortable one-handed use

• No horizontal scrolling

• Large touch targets

• Fast loading on 4G

• Responsive typography

• Safe-area support for iPhone Dynamic Island and Android cutouts

• Support both portrait and landscape



Animations must adapt to screen size.



Avoid desktop-only effects.



The story should remain cinematic on mobile.



Target 60 FPS on modern smartphones.



Lazy load heavy assets.



Reduce particle count automatically on weaker devices.



Respect prefers-reduced-motion.



Optimize every image and animation.



The mobile version must not feel like a reduced version—it should feel like the primary experience.
